Pizza Kilat (Lightning Pizza) — an original wood-fired pizzeria game built for the make.fun best cooking game bounty. One pizzaiolo, one 150-second dinner rush: stretch the dough, spread sauce and cheese, add the toppings each order asks for, bake it in the wood-fired oven — pull it out in the golden window or it burns — slice, box, and serve it before the customer loses patience. 6 recipes, 2 oven slots, combo multipliers and speed bonuses.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD / arrow keys or click, use stations with E, Space to start, P to pause.
